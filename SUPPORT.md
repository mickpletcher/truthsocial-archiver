# Support

Start with the [README](README.md), including setup, search, updates, limitations, and troubleshooting. This is a community-maintained project without a guaranteed support response time.

## Public help

Use [GitHub Issues](https://github.com/mickpletcher/truthsocial-archiver/issues/new/choose) for usage questions and the provided bug, feature, or accessibility forms. Search existing issues first. Include your app version or commit, OS, browser if applicable, steps tried, and sanitized error text. State whether you are using Electron, a local web server, local synchronization, or an upstream source update.

Do not include tokens, cookies, credentials, private paths, personal files, or full archive dumps. Screenshots are optional; text descriptions are welcome. This repository does not currently use GitHub Discussions.

## Archive accuracy and content concerns

The archive currently tracks only `@realDonaldTrump` through CNN's public dataset. CNN controls source availability and completeness. Existing records are append-only; engagement counts are snapshots, and deleted or edited upstream posts may remain. Media is linked rather than copied. Archival inclusion is not endorsement or verification of a statement.

For a non-sensitive missing, duplicate, or incorrect record, use the bug form and include its public post URL or ID and the relevant date. A report does not automatically change or remove archived records. For privacy, removal, copyright, or other sensitive concerns, open an issue asking only for a private contact method. Do not publish the sensitive material or allegation. A dedicated private contact channel and resolution timeframe are not currently documented.

## Other routes

- [Accessibility](ACCESSIBILITY.md): barriers and review guidance.
- [Security](SECURITY.md): potential vulnerabilities; do not post exploit details publicly.
- [Code of Conduct](CODE_OF_CONDUCT.md): community behavior and reporting.

This project cannot provide support for Truth Social accounts, CNN services, or third-party media sites. Current desktop artifacts are unsigned test builds; see the README's installer limitations. Do not treat support instructions as a reason to disable system security protections.
